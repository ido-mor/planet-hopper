Planet Hopper — Level Editor

Edits the play order and what each planet asks. Nothing here changes the game until you ship the file.
Heads up: reordering, adding, removing or retuning a level resets saved progress on every device the next time the game opens (the child sees “New missions!” and starts from planet 1). Renaming a level or its blurb does not.

Play order

After the last level the game keeps going by revisiting earlier levels in a random order, each on a new planet colour.

Ship it

  1. Replace levels.js in the repo with the download.
  2. Bump CACHE_NAME in sw.js (v22 → v23 …).
  3. Commit and push. Installed copies pick it up on next open.
